# Licensing decision

ProductionOS is released under Apache-2.0. The license provides a permissive grant for use, modification, and redistribution while including an express patent license and clear treatment of contributor changes. That fits a production-oriented tool intended for individual developers, teams, and commercial adopters.

The canonical license text is in the repository root at [`LICENSE`](../LICENSE). This project is not a compliance certification service; users remain responsible for reviewing their own dependencies and deployment obligations.
